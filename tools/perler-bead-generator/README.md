# 拼豆图纸生成器

纯前端的图片转拼豆（Perler / Hama 熨烫豆）图纸工具，无需后端、无需构建，双击 `index.html` 或部署到任意静态网站即可使用。

## 功能

- 上传图片，按"在家用什么纸打印"（A4/A3）自动推荐图案尺寸，实时显示预计的物理尺寸和用豆颗数；图案比一张纸大时，打印会自动拆成多页、留重叠对齐区
- 两套色卡可选：内置通用参考色卡（96色）、MARD 221 标准参考色卡
- 两种配色模式：
  - **智能推荐配色**：不用猜要多少种颜色，点生成时会分析这张照片本身的颜色分布，自动决定用几种、用哪些颜色最合适
  - **只用我现有的颜色**：手动从色卡里勾选，或上传自己拼豆颜色的照片、点照片上的色块自动取色加入——图纸只会用到选中的颜色，并给出"还原度"评分和具体的缺色建议
- 颜色匹配基于 CIELAB 色彩空间 + CIEDE2000 色差公式（贴近人眼感知，而不是简单的 RGB 距离）
- 智能去毛刺：轻微提升对比度/饱和度后再匹配颜色，并对孤立噪点做保留细节的降噪，让人像/宠物照片的眼睛鼻子更清楚、毛发不花
- 生成彩色图纸（网格线 + 每 10 格粗线定位)，也可一键切换为黑白符号图（适合打印后用符号对照拼豆，不依赖彩色打印机）
- 自动统计每种颜色的用豆颗数、占比,并可导出 PNG 图纸和 CSV 用豆清单
- 额外提供"布料印花高清图"导出：去掉网格线、放大到印刷清晰度的纯色块大图，适合定制印花/抱枕/布料
- "打印图纸 + 清单" 按钮可直接调用浏览器打印，生成可装订的纸质图纸（大图自动分页）
- 图片全程在浏览器本地处理，不会上传到任何服务器

## 使用

直接打开 `index.html`，或部署到静态托管（GitHub Pages / Vercel / Netlify / 自建服务器均可）。

## 色卡数据与准确度说明

- **通用参考色卡**：内置的通用参考色号（C01、C02 …），不对应任何具体品牌的官方编号，仅供颜色分类使用。
- **MARD 221 标准参考色卡**：色值取自开源项目 [maxcleme/beadcolors](https://github.com/maxcleme/beadcolors)（MIT 协议）的 `raw/mard.csv`，是社区整理的数字参考色值（屏幕/扫描色卡的近似 RGB），**不是** MARD 官方用分光测色仪测量的实体豆绝对色值——不同生产批次、不同显示设备都会带来细微色差。购买豆子前请对照你手上的实物色卡核对，如发现色号偏差欢迎反馈修正。
- 两套色卡下，购买豆子前都建议以实物色卡为准。

## 已知不在当前版本范围内的功能（欢迎作为后续需求提出）

- 其他品牌官方色号（Perler、Hama、Artkal 等）——需要有可信来源的品牌色卡数据后再接入
- 按库存颗数做用量优化/缺料清单/替代色建议——这是一个不同性质的算法（数量约束下的像素分配问题），需要单独开发
